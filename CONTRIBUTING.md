# Quy uoc lam viec voi Git

## Branch
- `feature/<ten-chuc-nang>`: tinh nang moi
- `fix/<ten-loi>`: sua loi
- `db/<noi-dung>`: thay doi database
- `docs/<noi-dung>`: tai lieu
- `test/<noi-dung>`: test

## Commit
- `feat:` tinh nang moi
- `fix:` sua loi
- `db:` database
- `docs:` tai lieu
- `test:` kiem thu
- `refactor:` tai cau truc code
- `chore:` cau hinh / cong viec phu tro

## Workflow
1. `git checkout main`
2. `git pull origin main`
3. Tao branch moi.
4. Commit va push branch.
5. Tao Pull Request vao `main`.
6. Cho Code Owner review/approve.
7. Chi Code Owner merge vao `main`.
