# Nhom06 - He thong quan ly nhan su va tien luong

Project cuoi ky mon He quan tri co so du lieu (DBMS330284).

## Cong nghe
- Java Swing
- JDBC
- Microsoft SQL Server

## Quy trinh Git
- Khong push truc tiep vao `main`.
- Moi task tao branch rieng: `feature/...`, `fix/...`, `docs/...`, `db/...`.
- Push branch len GitHub va tao Pull Request vao `main`.
- Code Owner review va approve truoc khi merge.

## Cau truc du kien
- `src/`: ma nguon Java
- `database/`: script SQL Server
- `docs/`: tai lieu, diagram, screenshot, report
- `.github/`: CODEOWNERS va Pull Request template
